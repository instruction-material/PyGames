# PyGames Structure

The repository backs `PyGames`. The 34 existing generated projects use shared
readings with `starter/` and `solution/` roles. `images/`, `music/`, and `sounds/`
remain shared asset roots; a link to one of those roots is not a runnable pack.

The three `PG-CORE-*` folders provide self-contained window/asset, image-anchor,
and integrated-game examples. Each selected role has `main.py`, its task module,
`contracts.py`, `requirements.txt`, `observations.md`, and `images/alien.png`.
The shared README belongs to the complete exported project. The declared task
module is the only starter/reference difference; assets and contracts agree.

The original 46 top-level Juni programs and media are retained. The original
master file is an open-ended brief; the Arena Delivery reference is newly
authored. `Check-in-2-Starter.py` and `Check-in-3-Starter.py` are previously
authored classroom starters distinct from their top-level solutions.

`test/verify_core_projects.py` owns all native child processes and evidence.
`test/observe_core_native.py` is a test-only sidecar that observes unchanged
programs in real SDL loops. Neither file belongs in learner imports. The CI
workflow validates twelve profiles and retains screenshots, source hashes,
raw process output and explicitly scoped runtime observations.

SOURCE_BACKLOG.md until course integration meets its promotion criteria.
