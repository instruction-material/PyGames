# PyGames Structure

This repository backs `PyGames`. Most active generated projects use
`README.md`, `starter/`, and `solution/`, while `images/`, `music/`, and
`sounds/` are shared asset roots.

`Check-in-2-Starter.py` and `Check-in-3-Starter.py` are course-wide classroom
starters authored from the current lesson objectives. They are intentionally
incomplete and are distinct from the corresponding top-level solution files.

Generated project folders should use complete deterministic `PG-*` slugs. Do not
truncate words in folder names, and do not add unlinked top-level variants beside
the active course surface.
